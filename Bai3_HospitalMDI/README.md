# Bài 3 - Quản lý bệnh viện MDI

- Mở `Bai3_HospitalMDI.csproj` bằng Visual Studio 2026 và nhấn F5.
- Form cha là MDI Container. Menu Quản lý mở hồ sơ bệnh nhân, lịch trực bác sĩ, khoa/phòng; mỗi loại Form chỉ mở một lần và sẽ Activate nếu đã tồn tại.
- Menu Cửa sổ hỗ trợ Cascade, Tile Horizontal, Tile Vertical và đóng tất cả.
