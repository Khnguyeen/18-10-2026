# Bài 1 - Quản lý hội viên Gym

- Project C# Windows Forms, target .NET 10 (`net10.0-windows`).
- Mở `Bai1_GymMemberManager.csproj` bằng Visual Studio 2026 và nhấn F5.
- Giao diện và DataGridView được tạo hoàn toàn bằng code. Có thêm/sửa/xóa/làm mới, BindingList/BindingSource, ErrorProvider và xác nhận xóa.
- Phí dịch vụ nhập số nguyên dương; số điện thoại đúng 10 chữ số; tên chỉ gồm chữ và khoảng trắng.
