# Bài 2 - Quản lý sách và báo cáo

- Mở `Bai2_BookManager.csproj` trong Visual Studio 2026, chạy bằng F5.
- Có MenuStrip, ToolStrip, StatusStrip, quản lý sách, chọn ảnh bìa, tìm kiếm và nhập/xuất CSV.
- CSV có header: `BookId,Title,Author,Price,Quantity,CoverPath`. Đường dẫn ảnh được lưu trong dữ liệu; nếu chuyển máy, cần giữ ảnh ở đường dẫn tương ứng.
